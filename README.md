# Flutter Expense Tracker

A responsive Expense Tracker application developed using Flutter and Dart as part of my Flutter Development Internship at Auspify Technologies.

## Features

- Add, edit, and delete expenses
- Record expense title, amount, category, and date
- Calculate total spending automatically
- Filter expenses by category
- Visualize category-wise spending using progress bars
- Save and restore expenses using SharedPreferences
- Responsive and scrollable dashboard
- Input validation

## Technologies Used

- Flutter
- Dart
- SharedPreferences
- Material Design

## How to Run

1. Install the Flutter SDK.
2. Clone the repository.
3. Open the project directory.
4. Run `flutter pub get`.
5. Run `flutter run -d chrome --web-port 8082`.

## Testing

Run `flutter analyze` and `flutter test` to verify the application.
